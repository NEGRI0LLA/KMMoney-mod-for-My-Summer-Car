# ENG:

### KMMoney it is mod for game My Summer Car, witch add new way to earn money.

For every kilometer you drive in the Satsuma, you will earn money; the amount can be adjusted in the mod's own settings.

This mod requires MSCLoader to work.

### installation:

Put .dll file in mod folder for msc

# RU:

### KMMoney — это мод для игры My Summer Car, который добавляет новый способ заработка денег.
